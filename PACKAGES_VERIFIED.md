## 📋 Package Purposes

### expo-auth-session

- Handles OAuth flows
- Opens authentication in browser
- Manages redirect callbacks
- Used for Google and GitHub Sign-In

### expo-crypto

- Generates secure random values
- Creates nonces for OAuth
- Cryptographic operations

### expo-web-browser

- Opens URLs in in-app browser
- Handles OAuth redirects
- Better UX than external browser

### expo-apple-authentication

- Native Apple Sign-In on iOS
- Handles Apple ID authentication
- Manages Apple credentials

### expo-build-properties

- Configures native build properties
- Links Firebase config files
- Sets up Google Services
