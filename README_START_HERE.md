## ⚡ Quick Start (5 Minutes)

### For Expo Go Testing:

1. **Get Web Client ID:**

   - Go to: https://console.firebase.google.com/
   - Project: `managemate-32f1d`
   - Authentication → Sign-in method → Google
   - Copy Web Client ID

2. **Add to .env:**

   ```env
   EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=your-web-client-id.apps.googleusercontent.com
   ```

3. **Start app:**

   ```bash
   npm start -- --clear
   ```

4. **Test in Expo Go** ✅
